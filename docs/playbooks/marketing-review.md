# Marketing review — 行銷審查關卡（技術 QA 抓不到的那一層）

> 宣傳片、發表片、廣告這類「要讓人想要」的影片，除了技術 QA（規格、響度、拍點、ASR、隱私），一定要有一位以**行銷／創意總監**視角審片的人（或一個專門扮演這個角色的 agent）。這一節來自一次真實的教訓。

## Why — 一次真實的教訓

一支產品發表片通過了所有技術檢查：解析度、−14 LUFS、切點全部踩在拍上、旁白 CER 幾乎為 0、私有詞掃描乾淨，構圖也由 lead 逐輪看過 contact sheet。交給業主後，第一句回饋是「**有點恐怖**」：程序建模的商品是一團團漂浮的幾何形狀，其中一個小物件「像藥丸」。業主接著問：「**有 marketer 在審查嗎？**」

沒有。技術 QA 問的是「做得對不對」，行銷審查問的是「**看了會不會想要**」——這兩件事完全不同。補上行銷審查後，同一支片在兩輪內找出了十幾個技術上「沒錯」、但會讓產品顯得廉價或讓觀眾困惑的問題。

## Gates — 放在流程的哪裡

| 時機 | 審什麼 | 結論 |
|---|---|---|
| 腳本／分鏡 | 開頭 3 秒的鉤子、每顆鏡頭要傳達的價值、文案語氣 | 改稿 |
| **半解析試渲 contact sheet** | 下面整份清單 | GO 方向／修改清單 |
| **4 張 1080p 關鍵靜態圖** | 只審最關鍵的幾格（主角畫面、高潮、CTA）在全解析度下的細節：臉、手、商品質感、文字 | GO final（之後才跑完整 render） |
| 成片（連字幕、連聲音） | 從頭到尾看一次 | 交付／小修 |

用「4 張 1080p 靜態圖」代替「先 render 整支再看」：在 CPU 機器上，一輪完整 render 要一小時以上，靜態圖只要幾分鐘。

## Checklist — 行銷審查清單

**吸引力與質感**
- [ ] 開頭 3 秒有沒有抓住人？（沒字、沒聲、只有暗場 = 會被滑走；投影場合也會冷場）
- [ ] 產品／商品看起來**讓人想要**嗎？有沒有任何東西看起來廉價、詭異、像沒做完（空白卡、剪紙圖示、無法辨識的形狀）？
- [ ] 有沒有恐怖谷：無頭的人形、沒有臉的假人、畸形的手指或腳？
- [ ] 色調是否和品牌一致？冷藍暗場很容易變「恐怖片」，品牌是暖色就用暖色暗場。

**文案與畫面一致**
- [ ] 把**畫面和旁白／字幕並排比對**：旁白說「你還沒有的，我們幫你找」，畫面推薦的卻是使用者已經擁有的品項——這種邏輯錯誤只看畫面不會發現。
- [ ] 標籤和情境要和畫面內容相符（正式場合的畫面配休閒情境的標籤會很突兀）。
- [ ] **最有力的字眼留給高潮**：同一個標語不要在相鄰兩顆鏡頭各用一次，否則高潮時就沒有衝擊力。
- [ ] 畫面上出現的日期、星期、月曆排法要和真實月曆一致。
- [ ] 圖示能表達的不要再寫字（文字和圖示講同一件事就是重複）；標籤越短越好讀。
- [ ] 括號裡的權限或免責字樣放在字幕裡會削弱氣勢——移到畫面角落的小標。

**品牌**
- [ ] 品牌色要在**算圖後的成品**上實際取色比對，不能只看材質設定：3D 的 emission、bloom、色調映射會把橘推向紅或粉。
- [ ] 字標照官方檔案取樣，不要照 brief 的文字描述。

**合規與風險**
- [ ] 沒有價格、點數、網址、真實帳號（除非刻意要放）。
- [ ] 避開之後外流會麻煩的道具（酒精、品牌 logo、可辨識的真人）。
- [ ] AI 生成的人物標示「示意」，並在 1080p 下逐張檢查臉、手、手指、腳。

## Techniques — 好用的修法

- **商品不要用程序建模**：有自己的商品照片時，一律做成 3D **照片卡**（圓角、柔陰影、輕微厚度、視差），比程序建模更有質感。程序建模只留給抽象元素（字標、介面、光效）。
- **用不同人的照片示範「同一個人」的不同狀態**：把照片統一裁到下巴以下，觀眾就會看成同一個人。挑姿勢、取景接近的照片，避開手拿物品（AI 手指最容易出錯）和搶戲的背景。
- **做一條故事線**：讓同一個「主角」（同一個產品或同一組內容）貫穿每顆鏡頭——出場 → 使用情境 → 推薦 → 延伸購買——整支片就會變成「一個人的一天」，而不是功能清單。
- **素材分組不重疊**：「使用者已經有的」和「推薦給使用者的」兩組素材完全分開，避免畫面自相矛盾。
- **審查要逐秒抽格**：每顆鏡頭只抽一兩張的 contact sheet 會漏掉一閃而過的畫面（這次最嚴重的那一格只出現約半秒）。成片至少每秒一格。

## Running it as an agent — 用 agent 扮演行銷審查

給它：品牌基底（官網定位、色票、字體、目標族群）、腳本、業主的回饋。要求它**自己抽格看**（不是只看別人挑好的 contact sheet）、讀旁白文字、輸出 MUST-FIX／SHOULD／NICE 三級清單，每項附具體的創意修法，最後給 GO 或修改清單。它不需要任何技術指標——要的是誠實、具體的行銷眼光。

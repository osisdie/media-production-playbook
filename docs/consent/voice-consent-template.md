# Voice consent record (template)

Fill this in **before** cloning anyone's voice, keep it next to the (private, never committed) reference audio, and keep a copy of the written consent (email or chat message is fine).

| Field | Value |
|---|---|
| Speaker (name or pseudonym) | |
| Consent given by / on (date) | |
| Form of consent | written (email / message) — attach or reference |
| Scope of use | e.g. "narration for <project> only" |
| Commercial use allowed? | yes / no — date confirmed |
| Distribution | private only / public video / public repo (public repos: **never** include the voice) |
| Withdrawal | how the speaker can withdraw consent, and what you delete then |
| Reference audio | file name(s), duration, SHA-256 |
| Models used | name, version/commit, license |

Notes
- Open-source licenses (Apache-2.0, MIT) cover code and weights, **not a person's voice**. Consent is what matters.
- Never imitate celebrities or public figures, and never clone a voice from a recording you found online.
- Label generated audio (e.g. `-clone` in file names) and keep reference audio local only.
